# BRUS AI

BRUS AI is a desktop assistant application with a graphical interface and backend modules for chat, speech, automation, real-time search, and image generation.

## Setup

1. Create and activate a Python virtual environment.
2. Install the project dependencies:

   ```powershell
   python -m pip install -r Requirements.txt
   ```

3. Configure any required service credentials in a local `.env` file. Do not commit this file.

## Run

Start the application from the repository root:

```powershell
python main.py
```
